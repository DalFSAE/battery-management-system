# 03-Design

## Preliminary Research
STM32G4 series:
- Arm Cortex M4 processor - has powerful DSP and an integrated FPU, while still having low power consumption
- Dedicated math accelerators - can be used for trigonometric and filter functions
- Fast ADCs - ideal for fast moving or high frequency signals
- High resolution timers - more accurate time measurements and control
- Built in support for USB type C power deliveries and CAN FD
- Inexpensive - options typically range from 6$ - 15$ on Digikey
